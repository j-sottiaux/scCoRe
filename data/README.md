# Data

The 15 scRNA-seq datasets used with scCoRe are available from Zenodo:

https://doi.org/10.5281/zenodo.15272789

The archive contains Bach, Goolam, Hrvatin, Melanoma, Muraro, Petropoulos,
Pollen, Bladder, Limb muscle, Diaphragm, Shekhar, Tosches, Worm neuron, Yan and
Young. Download only the required `.h5` files and place them in this directory.
Dataset files must not be committed to the repository.
